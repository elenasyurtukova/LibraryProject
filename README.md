# Проект реализации приложения управления библиотекой на базе Django REST framework
## В проекте реализовано:
1. Приложение library:
* в модуле models приложения описаны модели для автора, книги и выдачи книги
* в модуле views приложения реализованы классы для создания/изменения/удаления/просмотра авторов и книг,
определены права доступа, функции с описанием логики выдачи книги и создания записи в журнале выдачи и 
функция с описанием логики возврата книги
* в модуле urls приложения прописаны пути для контроллеров
* в модуле serializers описаны классы сериализаторов для моделей автора, книги и выдачи книги
2. Приложение users:
* в модуле management/commands/csu реализовано создание суперпользователя
* в модуле models приложения описана модель пользователя
* в модуле serializers описан класс сериализатора для модели пользователя
* в модуле urls приложения прописаны пути для контроллеров 
* в модуле views приложения реализованы классы для создания/изменения/удаления/просмотра пользователей,
определены права доступа, реализована аутентификация и авторизация пользователей с использованием JWT токенов
3. Автогенерируемая документация API по стандарту OpenAPI с использованием инструмента drf-yasg

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/LibraryProject.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```

3. Создайте файл .env в корне проекта и добавьте туда необходимые переменные окружения, указанные в файле .env.sample.

## Запуск проекта с помощью Docker Compose

Этот проект использует Docker Compose для запуска всех необходимых сервисов одной командой. 

## Подготовка к запуску  и запуск проекта:
1. Установите Docker Desktop для вашей операционной системы и запустите его.
2. В терминале, перейдите в директорию проекта. 
3. Запустите команду: docker-compose up -d --build

После запуска веб-приложение будет доступно по адресу: http://localhost:8000

## Дополнительные команды:

1. Для просмотра запущенных контейнеров: docker-compose ps
2. Для просмотра логов всех контейнеров: docker-compose logs
3. Для остановки сервисов и удаления контейнеров: docker-compose down -v.
